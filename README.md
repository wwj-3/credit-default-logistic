# 信用卡违约风险影响因素分析 (Credit Default Logistic)

## 📌 项目背景
本项目使用 `ISLR2` 包中经典的 `Default` 数据集（包含 10,000 名信用卡用户的记录），探讨学生身份、信用卡余额和收入与违约风险之间的关系。通过构建单因素与多因素 Logistic 回归模型，揭示变量间的独立效应与混杂效应。

## 🛠️ 分析方法
- **描述性统计**：使用 `gtsummary` 制作基线特征表（Table 1），展示违约组与非违约组在各项指标上的差异。
- **双变量分析**：对分类变量使用卡方检验，对连续变量使用 t 检验，并计算单因素 Logistic 回归的粗 OR 值。
- **多因素建模**：构建多因素 Logistic 回归模型，计算调整后的 OR 值（Adjusted OR），对比控制其他变量前后的效应变化。
- **模型诊断**：使用 VIF 检验多重共线性；绘制 ROC 曲线评估模型区分度（AUC）；构建混淆矩阵分析模型在不平衡数据下的分类表现。

## 🔍 核心发现：辛普森悖论 (Simpson's Paradox)
本项目最大的发现是经典的**辛普森悖论**现象：
- 在**单因素分析**中，学生身份（`student`）的粗 OR 值 < 1，看似是“保护因素”（学生更不容易违约）。
- 但在**多因素回归**中，控制信用卡余额（`balance`）后，学生身份的 OR 值反转为 > 1，变成了“风险因素”。
- **结论**：学生群体整体违约率较低，是因为他们的信用卡余额往往较低。一旦控制了余额，学生身份本身反而增加了违约风险。这证明了在数据分析中，双变量分析与多因素分析相结合的必要性。

## 📁 文件结构
- `R/`：包含数据清洗、描述性统计、建模等独立 R 脚本。
- `reports/`：包含 R Markdown 源文件（`.Rmd`）及最终生成的 HTML 分析报告。
- `data/`：数据集说明（数据由 `ISLR2` 包提供）。
